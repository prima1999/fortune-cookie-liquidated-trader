A Node program (stdlib only) that writes one fortune cookie line for a crypto trader who just got liquidated — a real fortune voice with a joke that lands on the loss: "Your lucky numbers are 0, 0, 0, and 0 — the exchange has already played them for you."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
